Privacy Policy

Last updated 23 November 2026

“WW2 Battles Publisher” is a private tool used only by the operator of the WW2 Battles accounts to upload our own history videos to our own social media accounts (TikTok, YouTube, Instagram, Facebook). It is not offered to the public.

What it accesses

When the operator signs in, the platform gives the tool an access token for the operator's own account and basic profile information (account ID and display name), used only to confirm which account videos are uploaded to.

What it stores

Tokens are stored only on the operator's own computer. Nothing is sold, shared with third parties, or used for advertising or tracking. The tool collects no data about viewers or other users.

This website

This site is a static page on GitHub Pages. It uses no cookies, analytics or trackers. GitHub may log standard request data as described in its own privacy statement.

Deleting data

Access can be revoked at any time in the platform's account settings (for TikTok: Settings → Security → Manage app permissions), after which stored tokens stop working and are deleted.
